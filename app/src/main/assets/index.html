AIDE Android IDE Deployment Guide

How to build in AIDE on an Android Phone:

  1. Create a new Java & Android project in AIDE named AirLink.
  2. Place index.html, css/style.css, and js/app.js in app/src/main/assets/.
  3. Add the Java files (MainActivity.java, DevicePairing.java, FileTransferManager.java, ScreenSharingService.java, NotificationListener.java, WebServerManager.java) to app/src/main/java/com/example/.
  4. Ensure AndroidManifest.xml contains the required permissions and service declarations.
  5. Tap Run in AIDE. AIDE compiles with its native AAPT2 and DEX toolchain with zero third-party dependencies!
